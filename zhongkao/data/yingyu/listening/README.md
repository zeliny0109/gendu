## 其他年份未取得的原因
- WebSearch：本会话的搜索额度（200 次，与其他 agent 共用）在本任务仅用 4 次后即耗尽，无法再检索。
- 教习网 51jiaoxi.com：搜到“专题09/12 福建-2022-2023年各地中考英语听力真题合集（含听力原文及MP3）”（doc-15370665、doc-15370737），但站点对 curl / WebFetch 均返回 Cloudflare 403 挑战页，未绕过。且该合集是“各地”卷，未必含全省统一卷。
- 21世纪教育网：逐页浏览英语试卷列表 zy.21cnjy.com/map/zy-4-7.htm，覆盖每年 6 月中旬到 7 月（2022–2026）的上传。福建全省卷只有 2025 年有带听力原文的版本；2022（12569500、12572319、12581148、12623537、12719061）、2023（16344820、16348712、16361065、16530999）、2024（20649245、20653681）、2026（26003502、26004147、26020947）的版本都注明“无听力原文”，或页面里确实没有原文。列表最早只能翻到 2022 年初，所以 2019–2021 查不到。
- 中学英语网 trjlseng.com：已查看中考试题栏目全部约 2400 篇的标题，福建只有 2020、2025 两篇，都是下载链接，没有听力原文。
- tesoon.com（2024 听力，只有音频下载）、夸克文档预览、高考直通车（要登录）、555edu：都没有公开的原文。
