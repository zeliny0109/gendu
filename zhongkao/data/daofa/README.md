### 2.2 模块
- M01–M23：七上～九下，共 81 个教材考点，粒度大致是“一框或一课”。
- M24 时政热点：`daofa.news.<年份>`，一年一个。凡是材料取自当年或上一年时政的题目，都加上这个标签。
- M25 题型方法：`method.choice`（组合式、排序、漫画图表、表格式时事解读等特殊选择题）、`method.judge`（判断说理）、`method.comment`（时事点评）、`method.analysis`（材料分析）、`method.open`（开放表达／等级评分）。每道主观题都标了一个方法考点。

### 2.3 标注规则
- 每题 1–3 个考点，主教材考点放第一个；超过 3 个时，按“主教材考点 > 时政 > 方法 > 次教材考点”的顺序取舍。
- `difficulty` 1–3 是转录人的主观判断。
- 真题中没考到的教材考点有 4 个：`g7a.life_nature`（探问生命）、`g8a.crime_prevention`（预防犯罪）、`g8a.build_country`（关心国家发展）、`g9b.lifelong_learning`（学无止境）。

## 4. 主观题答题模板（根据历年官方参考答案和评分说明归纳）

### 4.1 判断说理（第 26 题，2019–2021 年是第 27 题；共 8 分，两小问各 4 分）
**格式**：`（√/×）理由：` + **①评价行为/观点** + **②教材原理** + **③（可选）怎样做/意义**
- 判 √：“某某____（做了什么），____（体现/遵守/传承了什么）+ 原理，有助于____。”
  - 例（2026 26(2)）：“小福用行动表达孝敬之心，传承了中华民族传统美德，有助于增进亲情，促进家庭和谐。”
- 判 ×：“先肯定对的部分，再指出错在哪里 + 正确观点”。
  - 例（2023 26(2)）：“经历挫折不一定能成功。如果能正确对待挫折……就有可能成功；如果一味沉浸在……就难以成功。”
  - 例（2026 26(1)）：“小福能通过他人评价认识自己的不足，**但**未能主动改正缺点……”
- 陷阱：题干中有“只要……就……”“一定”“总是”等绝对化说法（2021 27(1)），或只说对一半（2024 26(2)“网络信息”），这类都判 ×。
- 常考七年级、八年级上册内容：自我认识、友谊、孝亲、挫折、文明礼貌、网络、权利界限、安全。

### 4.2 时事点评（第 27 题，2019–2021 年是第 28 题；6 分）
**格式**：**①定性（是什么/体现什么）** + **②意义（为什么，分国家、人民、世界等层次）** + **③（可选）措施、要求**
- 2024（以旧换新）：“是释放内需活力、让更多发展成果惠及民生的重要举措；能促进消费，拉动投资……实现资源循环利用，节能降碳……”
- 2025（医保码、住房）：“共同体现了国家重视保障和改善民生。医疗和住房都是人民最关心最直接最现实的利益问题，我国坚持以人民为中心……”
- 2026（“十五五”约束性指标）：“强化底线思维，体现对生态文明、国家安全的重视。……加强生态文明建设，能……；维护国家安全，能……”
- 2021（知识产权保护）：“我国重视知识产权保护。保护知识产权是……的需要，是……的要求，有利于……。保护知识产权，需要……”
- 常用语言：以人民为中心、增进民生福祉、新发展理念、高质量发展、文化自信、生态文明、总体国家安全观、人类命运共同体。

### 4.3 材料分析（第 28–30 题：原因、意义、启示、做法）
- **原因/必要性**（例如 2021 30(1) 反食品浪费法）：从材料里的每个现象找对应原理，按“现象 + 原理”一条一条写（“我国……问题突出，出台……为……提供法律依据；……是贯彻……基本国策的要求；……符合总体国家安全观的要求”）。
- **意义**：按“对个人、社会、国家、世界”分层，用“有利于／有助于／推动……”。
- **做法、措施**：按“国家、社会、学校、个人”分主体；题目指定了知识范围时，要用这部分知识（如 2021 30(2)“运用依法履行义务的知识”→“法律要求做的必须去做，法律禁止做的坚决不做”，再加具体行为）。
- 评分说明几乎都有“其他回答，观点正确，符合题意，可酌情给分”，按要点给分，**材料和原理要一一对应**。

### 4.4 开放性表达（等级评分，2022 年起每年都有，2026 年有 3 处）
题型：寄语（2022）、校园数字创意及价值（2023）、成长路径设计与感言（2024）、科普研究思路与行动（2025）、社区活动设计、承诺书、交通违规“行为—危害—防范”（2026）。
- 官方等级表的共同要求（最高水平）：**价值取向正确**、**紧扣题目给的主题或关键词**、**结合中学生实际、写出具体可行的行动**、**要素完整**（如“需求—行动—目标—新需求”“问题—分析—解决”“行为—危害—防范”）、**逻辑严谨、表述科学规范**、运用学科术语。
- 常见降档原因：只写一半（只写创意不写价值）、前后不对应、内容笼统、单纯罗列关键词。
- **模板**：点明主题 → 分条写出 2 条具体行动或要素（每条“做什么 + 为什么”）→ 用一句话升华。
