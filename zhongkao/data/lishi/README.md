转录约定：
- 纯文字的表格、时间轴、大事记，以及标了数值的柱状图、饼图，都转成了 Markdown 表格或文字，并在 note 里注明“已转为表格”。

- 非选择题的共用材料放在 `materials`（m29–m34），按小问拆题，`no` 写成 “30(2)”。
- 设问里的着重号在 note 里说明。
- 官方评分细则（如 2019 年的分项给分）写在 `rubric`。

## 4. 非选择题：设问类型与答题方法（依据官方答案与评分说明归纳）

| 设问类型 | 典型真题 | 官方答案的写法 / 得分要点 |
|---|---|---|
| **信息提取 / 识记**（2–3 分） | 2019-31(1) 支持国；2021-34(1)、2022-29(1) “以世纪、年代的呈现方式”写时间；2022-30(1) 侵台两国 | 直接答名词或时间。“世纪+年代”必须写成“19世纪60年代”。2019-32(1) 细则：完整写出变化过程“从平城迁到洛阳”得 3 分，只答“洛阳”得 1 分 |
| **概括特点 / 变化 / 趋势** | 2019-32(3) 改革特点；2023-31(1)(2) 着装；2024-30(2) 手工业品特点；2025-31(2) 航天事业特点 | 用四字短语分点答，如“汉化；涉及面广；自上而下”。数量按分值给，官方常注明“任答 X 点即可” |
| **原因 / 条件** | 2019-32(2)、33(3)；2021-32(2) 解放战争胜利原因；2023-31(3)；2024-31(1)；2025-31(1) | 从政治（党的领导、制度）、经济、科技、人民群众、国际环境等角度分层作答。材料信息和所学知识各占一部分 |
| **意义 / 影响 / 作用 / 价值** | 2019-33(2) 东方红一号；2024-30(1) 物候知识价值；2026-31(2) 中老铁路意义 | 对当时、对后世、对世界分层作答，答案一般列 4–8 个角度 |
| **目的 / 关系** | 2026-31(1) 列强修路目的；2024-31(3) 环保与经济；2025-30(1) 冶铁与农业 | 讲“关系”要写双向：A 需求推动 B，B 进步又反过来促进 A |
| **“你是否同意”评价题**（6 分左右） | 2019-31(2)、2021-31(2)、2022-29(2)、2023-29(2) | 格式为“判断 + 理由”。同意、不同意、辩证三种都可以得分。2019 年细则：判断 1 分，理由 3 分。最稳妥的写法是先肯定，再指出局限，最后落到“历史地、辩证地看待” |
| **史料实证 / 说服他人**（8 分） | 2024-29 布币判断年代；2025-15 实寄封；2026-29 “饼” | 从史料中提取至少两个信息，每个信息对应一个史实，再互相印证得出结论，例如“苏维埃政府”说明是土地革命时期，“长征前”说明在 1935 年以前，所以选 1933 年 |
| **史料辨析 / AI 辨析** | 2025-29 | 先指出材料中哪些对、哪些错，再说方法：交叉比对，用权威史料印证，不能用 AI 代替自己思考 |
| **图像解读** | 2025-32 景别；2026-32 海报；2023-30(1) 为歌词谱曲 | 描述画面元素，说明象征含义，联系史实，最后归纳主题。2023-30(1) 分等级评分：“低沉与铿锵结合”并完整结合史实的答案给一等 |
| **提炼主题**（2 分） | 2022-31(3)、2024-30(3) | 写一句完整的判断，如“劳动是文明与创新之源”。从劳动、科技、党的领导等角度都可以 |
| **小论文**（10–12 分） | 2019-34、2021-34(2)、2022-32、2023-32、2024-32(2) | 官方示例都用“观点—论述—结论”三段。要求观点明确，用两个材料事件，再加至少一个所学事件，做到史论结合。注意“不得选用示例”这类限制（2022），以及“两个”这类加着重号的数量要求 |

## 5. 福建乡土与地方特色命题

- **福建人物与事件**：福州船政局（2019-33、2023-11）；古田会议（2021-16 考史实与解释的区分，2022-32 示例）；林则徐、严复、陈嘉庚名言（2022-11）。
- **台湾与闽台关系**：郑成功从金门渡海收复台湾（2019-8）；台湾大事记，以及台湾书院与福建相似（2022-30，12 分）；元朝澎湖巡检司（2024-9）；《职贡图》中的高山族（2025-8）；清代《台湾府志》记载的中秋博饼（2026-29）。
- **海上贸易与海丝**：元朝市舶司（2026-8）；17–18 世纪中西物产交流（2022-10）；新航路带来的物种交流（2022-21、2023-20）。泉州本地题目目前还没有正面出过，可作为预测方向。
